## Pitch

A command called `--dry-run` should be observational. RustChain PR #8298 found a migration preview that could create UTXO schema objects and report the root of the wrong state. This package explains the bug, the testable safety property behind the fix, and why truthful previews matter in financial/stateful software.

## Included

- `script.md` — 4–5 minute narration
- `storyboard.md` — shot-by-shot production instructions
- `assembly.md` — edit/timing map
- `metadata.md` — titles, description, chapters and tags
- `SOURCES.md` — claim-to-source map
- `thumbnail.png` + two alternates — original generated title-card graphics
