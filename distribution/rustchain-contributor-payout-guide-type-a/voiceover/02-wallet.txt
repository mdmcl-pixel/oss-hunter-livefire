One of the clearest rules is easy to miss: you do not need an RTC wallet address before opening your pull request. The contributor guide says the project asks for the wallet during the payout step after the pull request is merged. That matters because payout setup should not block the engineering work. The sequence is review, merge, wallet request, then transfer from the community fund. Merged PR number 8271 added that clarification directly to CONTRIBUTING dot M D, so this is not an inferred workflow. It is a documented project rule.
